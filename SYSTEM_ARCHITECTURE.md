# System Architecture

## Architecture Components

1. Frontend: React application.
2. Backend: Node.js and Express REST API.
3. Database: MongoDB.
4. Version Control: GitHub.
5. CI/CD: GitHub Actions.
6. Containerization: Docker and Docker Compose.
7. Cloud: AWS.
8. Monitoring: Prometheus and Grafana.

## Application Flow

User -> React Frontend -> Express API -> MongoDB

## Deployment Flow

GitHub -> GitHub Actions -> Build -> Test -> Docker -> AWS
